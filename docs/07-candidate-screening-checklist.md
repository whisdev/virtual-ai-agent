# Candidate Screening Checklist

Use this when evaluating applicants for the AI Agent Architecture Consultant role.

## Must-Have

- [ ] **AI agent experience** — Has built or designed multi-agent or single-agent systems
- [ ] **OpenClaw/ClawBot familiarity** — Can speak concretely about architecture, not just heard of it
- [ ] **Architecture thinking** — Can discuss trade-offs, orchestration patterns, memory design
- [ ] **Communication** — Explains technical concepts clearly; asks good questions

## Nice-to-Have

- [ ] **German market / EU** — Experience with DACH, DSGVO, or European clients
- [ ] **Marketing/SEO/CRM domain** — Understands the business use case
- [ ] **Production experience** — Deployed agent systems to real users

## Red Flags

- [ ] Vague about OpenClaw ("I've read about it") without hands-on work
- [ ] Overpromises on timeline or scope
- [ ] No questions about our requirements or constraints

## Interview Prompts

1. "Walk me through an AI agent system you've built or worked on. What was the architecture?"
2. "How does OpenClaw's gateway/agent runner differ from a simple chatbot wrapper?"
3. "If we have 4 specialist agents (marketing, SEO, content, leads), how would you design the orchestrator?"
4. "What would you want to understand about our project before recommending an approach?"
